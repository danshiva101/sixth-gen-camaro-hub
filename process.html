How this website was created with AI

This page documents the project prompts, the AI actions, and the deployment path so the site meets the final-project requirement for a dedicated process page.

Prompt 1

"I want a websiter created all about the 6th gen Camaro"

Result: Codex planned and built a responsive website about the sixth-generation Chevrolet Camaro, covering the 2016-2024 model years, engines, trims, timeline, track packages, gallery, and final Collector's Edition.

Context file

"CSIT 212 Final Project.pdf"

Result: Codex read the assignment PDF and added this dedicated process page, source links, and a deployment-ready file structure so the project can be published as a public website.

Research step

"Verify Camaro facts before writing the page."

Result: Codex checked Chevrolet Newsroom and official spec sheets for key facts, including the final 2024 Collector's Edition, available powertrains, ZL1 output, and the 350-unit ZL1 Collector's Edition limit.

Build step

"Create the website files."

Result: Codex created index.html, process.html, styles.css, and script.js. The site uses responsive layout, an interactive engine selector, a timeline, image gallery, source list, and mobile navigation.

Prompt 2

"Add packages, options, model photos, colors, tires and wheels."

Result: Codex expanded the main page with a model lineup section, package and option cards, photos for LT, LT1, SS, ZL1, 1LE and convertible Camaros, a 2024 color swatch category, and a wheels/tires category with images plus a sizing table.

Prompt 3

"Remove best fit and compare LT1, SS, and ZL1 interiors."

Result: Codex removed the package footer labels and added an interior comparison section with side-by-side LT1, SS, and ZL1 dashboard photos plus short notes explaining how the cabin equipment changes between trims.

Prompt 4

"Add audio options and include LT/LT1 in the interior comparison."

Result: Codex added an Audio and Infotainment package card explaining the standard 6-speaker setup and Bose premium audio, then updated the interior comparison so LT and LT1 are grouped together before SS and ZL1.

Prompt 5

"Show the SS and LT1 wheels and tires, not the whole car, with sizing in the captions."

Result: Codex updated the wheels section with wheel-focused LT1 and SS images and added captions listing the wheel widths and tire sizes for the LT1 square setup plus the staggered SS front and rear setup.

Prompt 6

"Use LT, LT1 Carbon Flash, SS rear sizing, and ZL1 wheel and tire photos."

Result: Codex changed the wheels category to show clean wheel-only images for the LT, LT1 Carbon Flash, SS Carbon Flash note, and ZL1 setups, with captions explaining the wheel width and tire size for each model.

Deployment prompt

"I want to deploy this as a public website. Where should I put it?"

Result: Codex recommended GitHub Pages because the Camaro project is a static HTML, CSS, and JavaScript website. GitHub Pages can host it for free and provide the public website link needed for submission.

GitHub help prompt

"Ok, we can do GitHub. I don't have a GitHub account. Can you help me create one and upload the files there to make a website?"

Result: Codex explained that the student needs to create or sign in to a GitHub account, then upload the website files to a public repository and turn on GitHub Pages from the repository settings.

Prompt collection

"Can you collect all the prompts I have put here for this project and give a short description on the results under each prompt?"

Result: Codex collected the major project prompts and turned them into this process page, with a short result explanation under each prompt so it can be uploaded as part of the website.

Public link plan

Recommended deployment: GitHub Pages.

GitHub Pages is a good fit because this project is a static website. After the files are uploaded to a public GitHub repository, Pages can publish the site from the repository root and provide a public URL.

  1. Create a public GitHub repository.
  2. Upload index.html, process.html, styles.css, and script.js.
  3. Go to repository Settings, then Pages.
  4. Select the main branch and root folder.
  5. Submit the generated GitHub Pages link for the assignment.
