How I Built This Website with AI (CSIT 212 Requirement)

This page documents the prompts I used with AI and the output approach, as requested in the assignment submission instructions.

Prompt 1

I need a full website about the 6th generation Camaro for my CSIT 212 final. Build a responsive homepage with sections for trims, engines, timeline, and modding tips.

Result: AI generated the main structure and content sections for a complete enthusiast website.

Prompt 2

Style the site with a dark performance theme and accent colors inspired by Chevrolet motorsports. Make it modern and mobile friendly.

Result: AI created custom CSS with responsive cards, typography scaling, and performance-inspired color palette.

Prompt 3

Create a separate page that explains the prompts used and short descriptions of results so it can be uploaded with the website.

Result: This dedicated process page was created to satisfy the assignment requirement.

Prompt 4

How do I deploy this as a public website? Give simple options.

Result: Suggested deployment options include GitHub Pages, Netlify, and Vercel using this same project folder.
